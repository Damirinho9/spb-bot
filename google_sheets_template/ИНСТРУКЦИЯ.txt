ИНСТРУКЦИЯ ПО СОЗДАНИЮ GOOGLE SHEETS
=====================================

1. Создайте новую Google Таблицу: https://sheets.google.com

2. Импортируйте каждый CSV файл как отдельный лист:

   Для каждого файла (sources.csv, published.csv, settings.csv):
   - Файл → Импортировать → Загрузка → Выберите CSV файл
   - Расположение импорта: "Вставить новый лист"
   - Тип разделителя: "Запятая"
   - Нажмите "Импортировать"

3. Переименуйте листы:
   - Первый лист → "sources"
   - Второй лист → "published"
   - Третий лист → "settings"

4. Скопируйте ID таблицы из URL:
   https://docs.google.com/spreadsheets/d/[ВОТ_ЭТОТ_ID]/edit

5. Вставьте ID в n8n workflow или в переменную окружения GOOGLE_SHEET_ID

=====================================
ОПИСАНИЕ ЛИСТОВ
=====================================

SOURCES (источники):
- id: уникальный номер источника
- name: название для логов
- url: ссылка на источник
- type: telegram / rss / vk
- active: TRUE или FALSE

PUBLISHED (лог):
- Заполняется автоматически ботом
- Не редактируйте вручную

SETTINGS (настройки):
- telegram_channel: канал для публикации (@имя или ID)
- max_post_length: максимальная длина поста
- prompt: свой промпт (опционально, оставьте пустым для стандартного)
