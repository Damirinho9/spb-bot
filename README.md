# SPB Free Events n8n Bot

Этот репозиторий содержит шаблон n8n-воркфлоу для мониторинга бесплатных событий в Петербурге и публикации постов в Telegram.

## Что внутри

- `workflow/n8n-news-bot.json` — готовый воркфлоу с расписанием (11:00, 14:00, 18:00) и ручным запуском через webhook.

## Как использовать

1. Импортируйте JSON в n8n.
2. Создайте Google Sheets с двумя листами:
   - `sources` с колонками `name`, `url` (RSS-ленты).
   - `log` с колонками `source_id`, `title`, `link`, `published_at`, `posted_at`.
3. Укажите переменные окружения в n8n:
   - `GOOGLE_SHEET_ID` — ID таблицы.
   - `TELEGRAM_CHANNEL_ID` — ID/username канала для публикации.
4. Настройте креды Google Sheets, OpenAI и Telegram в нодах.
5. Активируйте воркфлоу.

## Точки запуска

- Расписание: 11:00 / 14:00 / 18:00 (ежедневно).
- Ручной запуск: `POST /webhook/spb-free-events-now`.

## Подсказки

- При необходимости замените модель OpenAI на OpenRouter или другой провайдер в ноде `Write Post`.
- Добавьте фильтрацию по ключевым словам в ноде `If New`, если нужно отсеивать нерелевантные новости.
