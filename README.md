# SPB Free Events News Bot

AI бот-новостник для Telegram канала "Бесплатный Петербург" на базе n8n.

## Возможности

- Автоматический сбор новостей из Telegram каналов, RSS-лент и VK
- AI-обработка новостей через OpenAI (GPT-4o-mini)
- Публикация в Telegram с фото (если есть в источнике)
- Защита от дублей через Google Sheets
- Фильтрация рекламы по стоп-словам
- Расписание: 11:00, 14:00, 18:00
- Ручной триггер через webhook

## Структура Google Sheets

Создайте Google Таблицу с 3 листами:

### Лист `sources` (источники)

| id | name | url | type | active |
|----|------|-----|------|--------|
| 1 | Питер Бесплатно | https://t.me/s/freepeterburg | telegram | TRUE |
| 2 | Free SPB VK | https://vk.com/freespb | vk | TRUE |

**Типы источников:**
- `telegram` - публичный Telegram канал (формат: https://t.me/s/channel_name)
- `rss` - RSS-лента
- `vk` - публичная страница VK

### Лист `published` (лог публикаций)

| content_hash | title | original_url | source_id | source_name | published_at | post_text | media_url |
|--------------|-------|--------------|-----------|-------------|--------------|-----------|-----------|

*Заполняется автоматически*

### Лист `settings` (настройки)

| key | value |
|-----|-------|
| telegram_channel | @kontentzavodn8npro |
| max_post_length | 800 |
| prompt | (опционально - свой промпт) |

## Установка

### 1. Импорт workflow в n8n

1. Откройте n8n
2. Создайте новый workflow
3. Нажмите `...` → `Import from file`
4. Выберите файл `SPB Free Events News Bot.json`

### 2. Настройка credentials

#### Google Sheets
1. В n8n: Credentials → Add credential → Google Sheets OAuth2
2. Следуйте инструкциям для подключения Google аккаунта
3. Дайте доступ к таблице

#### OpenAI
1. В n8n: Credentials → Add credential → OpenAI
2. Вставьте API ключ от OpenAI

#### Telegram Bot
1. Создайте бота через @BotFather в Telegram
2. Получите токен бота
3. В n8n: Credentials → Add credential → Telegram
4. Вставьте токен
5. Добавьте бота в канал как администратора

### 3. Настройка таблицы

1. Создайте Google Таблицу по структуре выше
2. Скопируйте ID таблицы из URL (между /d/ и /edit)
3. Замените ID в узлах Google Sheets или установите переменную окружения `GOOGLE_SHEET_ID`

### 4. Замена ID Google Таблицы

**ВАЖНО:** После импорта workflow необходимо заменить `ВАШ_GOOGLE_SHEET_ID` на реальный ID вашей таблицы в 4 местах:

1. Откройте workflow
2. Найдите узлы с Google Sheets (4 штуки):
   - "Читаем источники"
   - "Читаем опубликованные"
   - "Читаем настройки"
   - "Логируем в Sheets"
3. В каждом узле нажмите на него → в поле Document вставьте ID вашей таблицы

ID таблицы находится в URL: `https://docs.google.com/spreadsheets/d/[ВОТ_ЭТОТ_ID]/edit`

### 5. Активация

1. Проверьте все подключения (зелёные галочки на узлах)
2. **ОБЯЗАТЕЛЬНО:** Активируйте workflow (тумблер справа вверху должен быть ЗЕЛЁНЫМ)
3. Без активации:
   - Schedule триггер не будет срабатывать в 11:00, 14:00, 18:00
   - Webhook для ручного поста не будет работать

### 6. Тестирование

1. Нажмите кнопку "Test workflow" (зелёная кнопка сверху)
2. Это запустит workflow вручную и покажет результат каждого узла
3. Если есть ошибки - они будут показаны на проблемном узле

## Webhook для ручного поста

После активации workflow получит URL вида:
```
https://your-n8n.app.n8n.cloud/webhook/post-now
```

Для ручного запуска:
```bash
curl -X POST https://your-n8n.app.n8n.cloud/webhook/post-now
```

## Промпт по умолчанию

Бот использует следующий промпт для генерации постов:

```
Прочитай новость о бесплатном событии в Петербурге и создай пост для Telegram:

1. Эмодзи для категории в начале
2. Структура: название → дата → место → стоимость → описание
3. Убери HTML-теги и рекламные ссылки
4. Максимум 800 символов
```

Можно изменить в настройках (лист `settings`, ключ `prompt`).

## Troubleshooting

### Ошибка 403 при парсинге RSS.app
RSS.app требует платную подписку. Используйте прямой парсинг Telegram каналов (type: telegram).

### Нет постов для публикации
- Проверьте лист `sources` - есть ли активные источники (active = TRUE)
- Проверьте лист `published` - возможно все новости уже опубликованы

### Ошибка отправки фото
Бот автоматически отправит пост без фото, если изображение недоступно.
